# 🏙️ CivicVoice

CivicVoice is an AI-assisted civic reporting platform that helps citizens **report, locate, and track everyday civic issues**.

## Overview

CivicVoice simplifies the process of reporting community problems by allowing users to describe an issue through **text or voice**. The platform analyzes the report, identifies its **category and severity**, captures its **location**, and displays it on an **interactive map**.

Users can also track the status of their submitted complaints from **reporting to resolution**.

## Key Features

- 🤖 AI-assisted civic issue analysis
- 🎙️ Voice and text-based reporting
- 📂 Automatic category identification
- 🚨 Severity identification
- 📍 Location detection
- 🗺️ Interactive civic issue mapping
- 🔄 Complaint status tracking
- 👤 Personal complaint dashboard
- 🛠️ Admin workspace for managing reports
- 🔐 User authentication and access control
- 📊 Civic reporting statistics
- 📱 Responsive web interface

## How It Works

1. **Report** — Describe the civic issue using text or voice.
2. **Analyze** — The system analyzes the report and identifies its category, severity, and summary.
3. **Locate** — The issue is associated with its geographical location.
4. **Map** — The reported issue can be displayed on the interactive civic map.
5. **Review** — Administrators can review submitted complaints.
6. **Track** — Users can monitor the complaint status.
7. **Resolve** — Complaints move through the workflow: **Reported → In Progress → Resolved**.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python, Flask
- **Database:** SQLite
- **Mapping:** Leaflet, OpenStreetMap
- **Voice Input:** Browser Speech Recognition
- **Location:** Browser Geolocation API
- **Deployment:** Render
